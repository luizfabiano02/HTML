
# Meus Sites Favoritos

## Atividade 12 - Desenvolvimento de Sistemas I

Este projeto foi desenvolvido como atividade da Agenda 12 da disciplina Desenvolvimento de Sistemas I.

O objetivo da atividade foi criar uma página HTML simples para apresentar alguns dos meus sites favoritos.

## Sites escolhidos

1. Google
2. YouTube
3. Wikipedia
4. GitHub
5. W3Schools

## Tecnologias utilizadas

- HTML

## Como executar

1. Baixar os arquivos do projeto.
2. Localizar o arquivo HTML.
3. Dar dois cliques no arquivo.
4. A página será aberta no navegador.

## O que foi utilizado no código

- `<html>` para iniciar a página.
- `<head>` para informações da página.
- `<title>` para colocar o título na aba do navegador.
- `<body>` para colocar o conteúdo.
- `<h1>` e `<h2>` para os títulos.
- `<img>` para adicionar as imagens.
- `<a>` para adicionar os links.
- `<!-- -->` para escrever comentários no código.
